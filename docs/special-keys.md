# DataManager 特殊键

## 什么是「特殊键」

`DataManager` 存的是**全局配置**（`data.dat`），跨存档共享。
其中有一小类键被称为**特殊键**，它们的取值规则不同：

> 读取特殊键时，如果**当前存档**（`SaveDataManager`）里也写入了同一个键且值不同，
> 则**优先取存档里的值**。

也就是说特殊键同时具备两种身份：

- 作为**全局默认值**写在 `data.dat` 里；
- 允许**当前存档临时改写**，且不污染全局配置。

典型用途：某个存档需要「暂时不要退出」「临时关掉惯性」，
但不想把这份设置带回主菜单影响其它存档。

---

## 命名规范（强制）

| 规则 | 说明 |
|---|---|
| 内置键一律带 `starveil:` 前缀 | 例如 `starveil:inertia` |
| `starveil:` 是**引擎保留**命名空间 | 第三方不得占用 |
| 第三方注册的特殊键**必须**带自己的命名空间 | 例如 `myplugin:some_key` |
| 不带前缀的裸名会被**拒绝** | 见 `SpecialKeys.register` |

强制前缀的意义是「无歧义」：看到 `a:b` 就知道有命名空间，看到裸名就一定是历史遗留或写错了。

## 内置特殊键

### `starveil:cant_exit`

**剧情用的「禁止退出」标记。** 默认：不存在。

它是**为剧情保留**的键：剧情在需要强化代入感的段落里设置它，
让玩家在那一刻**无法退出游戏** —— 而不是随时点一下退出就把眼前的情境丢下。

比如一段不容打断的独白、一次无法回头的抉择，退出按钮的存在本身就会削弱张力；
关闭它，玩家才会真正「被困在那个场景里」。

**行为**：设为 `true` 时，**主菜单**与 **ESC 暂停菜单**都会移除「退出游戏」按钮；
设回 `false` 或移除该键即恢复。暂停菜单每次打开都会重建，
所以剧情中途改变标记会立刻反映到界面上。

它是**临时键**（不落盘，进程结束即消失），所以不需要任何清理逻辑。

### `starveil:inertia`

**移动惯性开关。** 默认：**开启**（`true`）。

- **开启**：玩家移动带加减速（松开方向键会滑行一小段），
  疾跑减速到静止期间播放**急停**贴图；
- **关闭**：恢复瞬时启停，且不再触发急停。

代码里通过 `DataManager.isInertiaEnabled()` 读取。
手感参数（加速度 / 减速度 / 急停阈值）在各实体的 `PlayerController` 上，
不在这个键里。

### `starveil:chat_history_keep_chapters`

**聊天记录是否跨章节保留。** 默认：**不保留**（章节切换即清空）。

- 默认（`false`）：每进入新章节清空聊天记录；
- 设为 `true`：记录一直留在内存里，直到手动清理或章节代码自行调用 `ChatHistory.clear()`。

无论哪种设置，记录都有 **1000 条**的内存上限，超出丢弃最旧的。
读取失败（例如配置尚未加载）时按「不保留」处理 ——
宁可多清一次，也不要因为读不到配置让记录无限堆积。

## 关于历史键迁移

**没有迁移。** 框架仍在测试阶段，不做历史数据迁移 ——
老存档与老配置**直接删掉即可**，不需要担心兼容。

`starveil:cant_exit` 曾经是无前缀的裸名 `CantExit`，现在裸名既不是特殊键、
也不会被映射：`SpecialKeys.migrate()` 只负责去空白。

刻意不写迁移逻辑，是为了不让「裸名曾经合法」这件事继续流传 ——
那只会让后来的人以为无前缀键是可接受的写法。

---

## 第三方如何注册特殊键

```java
SpecialKeys.register("myplugin:some_key");   // 返回规范化后的键
SpecialKeys.tryRegister("myplugin:some_key"); // 失败只返回 false
SpecialKeys.isSpecial("myplugin:some_key");
```

注册会被拒绝的情况：没有命名空间前缀、占用 `starveil:`、重复注册、空键。

## 别混淆：普通配置键

下面这些**不是**特殊键（不会走「存档覆盖全局」的逻辑），
但同样是 `DataManager` 里的键，顺带列一下常见的作用：

| 键 | 默认 | 作用 |
|---|---|---|
| `IllegallyShutdown` | 无 | 异常关闭标记；下一次正常启动时清理 |
| `plugin.consent_given` | `false` | 用户是否已同意加载插件（同意后不再弹窗） |
| `tutorial.completed` | `false` | 教程是否已完成 |
| `magic_circle.enabled` | `false` | 法阵（魔力）系统开关；关闭时魔力一律返回 0、不显示魔力条、Q 键无效 |
| `overlay.enabled` | **`true`** | 屏幕特效遮罩层开关；设为 `false` 时不创建全屏遮罩，故障花屏 / 伪蓝屏 / 降帧等特效随之不可用 |
| `setting.*` | 见各设置项 | 画面比例、全屏、音量、文字速度等设置 |
